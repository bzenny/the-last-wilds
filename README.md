# The Last Wilds

A GitHub-first, open-source Java/LWJGL game about monsters defending living wilderness from expanding human settlements.

## Status
Pre-alpha architecture and gameplay design. No verified desktop build yet.

## Design principles
- Simulation independent from rendering
- Data-driven creatures, factions and biomes
- Deterministic world ticks and seeded random generation
- Safe declarative add-ons before scripting
- Cross-platform automated builds

See `docs/GAME_DESIGN.md` and `docs/ARCHITECTURE.md` as they are added.
